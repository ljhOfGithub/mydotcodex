# 证据门控的 Research Proposal 写作

产出经得起直接近邻检验、且 Word 与 Markdown 相互一致的 research proposal。不得把文档写得漂亮、检索未命中、demo 能运行或应用故事合理，当作新颖性或有效性证明。

## 按需读取参考文件

- 为本用户工作，或需要还原既有四组 proposal 的意图时，读取 [用户主张与纠正](references/user-claims.md)。这些是用户要求，不是论文事实。
- 延续、比较或重构既有 Topic 时，读取 [助手候选思路与当前边界](references/assistant-ideas.md)。所有带日期的文献与新颖性判断都必须重新核验。
- 需要完整写作、审计和验收流程时，读取 [工作流与质量门](references/workflow-and-quality-gates.md)。
- 仅在需要配套 Markdown 或博导谈判材料时使用 [论证文档提纲](assets/defense-note-outline.md)。若已有权威 Markdown，应映射到原文件，不得创建重复文档。

## 核心工作流

1. **动笔前盘点。** 说明难度、时间估计、准确文件和计划。读取仓库规则、`paper-context.md`、用户提供的 DOCX 模板、当前权威 Markdown，以及有关 prior conversation 的证据。识别历史快照，不得让它们悄悄变成另一份“最新版”。
2. **分离主张来源。** 固定五类：用户要求、已核实申请人事实、论文支持事实、助手候选假设、尚未解决项。不得靠润色把一种来源变成另一种。
3. **先冻结科学问题，再接应用。** 先定义领域无关的研究对象、机制、benchmark、基线、外部效度目标和失败边界。教育平台、LCCA 或其他本地项目可以提供灵感、例子、基础设施或后期影子验证；除非用户明确选择应用型 proposal，否则它们不是新颖性来源或范围边界。
4. **按原子主张审计 Topic。** 把新颖性拆为可检索的句子。每条记录最接近的全文论文、已覆盖内容、未覆盖内容、最便宜的决定性实验、强简单基线，以及停止或收窄条件。一个直接反例足以杀死宽泛首创；检索未命中不能证明新颖。
5. **术语先定义，再承担理论功能。** 每个关键词标为`标准术语`、`论文专用术语`、`本文工作性定义`或`解释性类比`。已有定义时引用原始来源；综合形成时明确写“本文定义”，并列出组合的概念谱系。不得把表示当充分状态、把状态当策略、把主动观测当干预、把工程领域名当科学构念。
6. **科学命题可独立推翻。** 至少三条分别可失败：现象存在或可辨识；相同信息和成本下超越强基线；诊断或证据改进能转化为任务恢复或更低决策损失，且没有不可接受副作用。第四条可检验时间或跨域泛化。
7. **首轮快速决策，长期条件推进。** 前 8–12 周应建立或杀死核心现象，不能用一年只建少量探针。3–5 年计划是依赖图和停止图：测量、表示、决策、外部效度的前置门通过后，后续工作才继续。
8. **个人优势必须具体。** 写成`已核实经历 → 可立即执行的研究工作 → 降低的研究风险 → 证据边界`。既有软件和应用经历可支持问题接触与执行能力，但不能证明候选机制有效。
9. **应用联系必须闭环。** 使用`本地具体例子 → 通用科学抽象 → 领域无关与非应用验证 → 回到具体应用结果`。PolyU Education 4.0 必须指明学生、教师或治理流程及可测结果，不能只把标签当影响力口号。
10. **只生成用户要求的交付物。** 保留参考 Word 模板和用户要求的文件数量。正式 Word 与防御性 Markdown 可以面向不同读者，但用户只要一个文件时不能强制拆成两个。优先更新已有权威文件，不新建近似替代品。

## 文献与证据规则

- 使用适用的文献综述与全文精读流程。描述方法、数字或局限前，必须阅读论文正文和必要附录。
- 同时检索直接术语、相邻学科和同义词；对最接近论文做前向、后向引文扩展。记录检索日期，区分预印本、正式 venue、全文不可得和仅元数据记录。
- 剩余新颖性统一写成：“截至某日，在已记录的数据库、查询与引文范围内，尚未发现同时覆盖 X、Y、Z 的工作。”不得宣称调研已经完全穷尽。
- 每篇论文都解释**怎样支持**和**怎样限制**本题。专业词首次出现即用平实语言解释；密度高时维护紧凑术语表。
- 基线至少考虑非 LLM 规则、完整上下文或全量重写、简单去重、固定验证、随机动作、重复调用强模型，以及已经实现拟议组件的直接近邻。

## Word 与 Markdown 纪律

- DOCX 工作遵循已安装的 `documents` Skill：保留用户模板，使用 workspace dependency runtime，把每页渲染为 PNG，以可读缩放逐页检查，修复后重新渲染再交付。
- Word 在页数预算内承担正式研究叙事、引用、目标、方法、时间线、可行性和影响。
- 配套 Markdown 解释术语、个人优势、科研与工程边界、文献碰撞、决定性实验、kill gate 和博导挑战；不得与 Word 冲突或夸大。
- 任一文件改变题名、科学主张、时间线、引用状态或范围边界时，扫描全部权威对应文件及 MANIFEST／索引中的同类表述。

## 交付门

以下条件全部满足后才能交付：

- 每个中心术语都有状态和白话定义。
- 每句新颖性主张都有最近邻比较和带日期的证据边界。
- 每个目标都有可推翻命题、匹配基线、可测结果和停止条件。
- 第一年度包含快速决定性 pilot，没有人为拉长。
- 个人优势对应具体研究任务，并写明不证明什么。
- LCCA 或 Education 4.0 只按预定角色作为灵感、应用或验证，不意外变成 Topic 限制。
- Word 已逐页视觉检查；Markdown 链接和锚点可解析；两份文档的参考文献题名、年份和 venue 已核实。
- 最终回复报告本轮增量修改、完成的检查和仍存在的证据缺口。
