# 本地剪映口播加工流程

把用户提供的本地口播原片加工成可继续修改的剪映草稿和可交付成片。默认保留原文件，不发布，不购买会员。

## 开始前

1. 说明预计耗时、准备操作的文件和加工计划。
2. 确认输入视频的绝对路径；优先沿用用户指定的输出目录。
3. 用 `ffprobe` 记录时长、分辨率、帧率、视频编码和音频编码。
4. 在片头和有口播的位置抽查画面，判断字幕是否已经烧录进原视频。不要仅凭文件名推断。
5. 用系统本地应用“剪映专业版”（bundle id `com.lemon.lvpro`）；不使用浏览器版或调试端口 Chrome。

## 固定加工流程

1. 新建独立剪映草稿并导入原片，不覆盖原视频。
2. 把原片放到主时间线，核对时间线总时长与 `ffprobe` 接近。
3. 先用逐词时间戳审查口误、重复、无语义“嗯、呃、啊、呀”和相邻长停顿。每个删点写明源时间码、原词和理由；这些字承担疑问、列举、强调或句意时保留。源片已有烧录字幕时必须同步剪掉对应视频帧，不能只静音。
4. 内容粗剪后重新转写，确认目标口癖消失且相邻实词、句意、呼吸正常；然后才能按新的输出时间线列画面计划。后续所有 B-roll 和动画时间码必须重算，不能沿用源片时间码。
5. 在操作 GUI 前列出画面计划：时间点、口播观点、素材职责、时长、转场和验收帧。60–120 秒视频默认只在 3–5 个关键观点处使用 B-roll，每段约 1.5–3.5 秒，不要每句话都插图。
6. 若原片已经有同步字幕，保留内容粗剪后的烧录字幕，不重复识别字幕。
7. 若原片没有字幕：
   - 优先导入用户提供的本地 SRT；
   - 没有 SRT 时，先检查本机是否已有可用的离线转写工具；
   - 不把“智能字幕试用”当作永久免费功能。若导出要求登录或会员，撤销该功能，改用本地字幕方案。
8. 在第 0–3 秒添加一个片头钩子：
   - 从真实文案提炼，不添加没有依据的数据或承诺；
   - 默认一到两行，中文约 12–22 字；
   - 放在人物头部上方的安全区，不挡脸，也不挡原字幕；
   - 默认白字、黑色描边、居中；以实际画面可读性为准。
9. B-roll 优先使用真实录屏、真实文档/流程、关键词卡片，其次才是 AIGC 氛围素材。素材必须对应当前口播语义，不添加不存在的数据、公司或客户案例。
10. B-roll 默认使用 0.2–0.4 秒叠化进入和退出，原人声保持连续。同一条视频尽量只用一种主转场，不使用每句一转场的模板化包装。
11. 除非用户明确要求，不自动添加背景音乐、夸张转场、滤镜或美颜。
12. 避免带钻石、`SVIP`、会员权益或登录激活提示的功能。若用户明确要求会员功能，只说明限制并停在登录或购买前。
13. 导出前预览每个内容剪点前后、片头、每个 B-roll 中点、所有转场和结尾，确认没有吞字、爆音、字幕残留、画面错误或裁切。

## 旧版剪映的可靠兜底

当多轨素材在旧版剪映中无法稳定导入、导出后只剩原口播、出现不支持媒体或黑屏时，不要继续反复拖拽：

1. 按画面计划确定性预合成 B-roll 与透明度叠化，并映射原片连续音频。
2. 先验收预合成文件的关键中点和转场。
3. 新建全新空白剪映草稿，只导入预合成文件作为单一主片并加入时间线。
4. 在时间线缩略图中确认真人和所有 B-roll 均出现，再由剪映正式导出唯一命名的终版。
5. 对剪映最终导出文件重新做完整验收；不得用预合成文件的验收替代终版验收。

最终汇报必须明确这是混合路线，以及转场是在预合成阶段完成、剪映负责最终草稿和导出。不得把它描述成剪映原生多轨制作。

本机 bundle id 无法唯一连接时，使用明确应用路径 `/Applications/VideoFusion-macOS.app`。素材拖拽无效时可检查素材卡片的“添加到时间线”入口；GUI 操作超时后先重新连接应用并检查状态，不盲目重复点击。

## 导出规则

1. 优先保持原分辨率和帧率，口播竖屏通常为 1080×1920、30fps。
2. 选择 H.264 视频和 AAC 音频；码率使用推荐值或与源文件接近。
3. 输出名称默认使用 `<原文件名>_剪映加工版`，不得覆盖原文件。
4. 每次重试使用新的唯一文件名；失败文件保留并在 `project.md` 标记原因，不能把它当终版。
5. 若剪映免费导出只能生成 MOV，先正常导出，再用 `ffmpeg -c copy -movflags +faststart` 无损封装为 MP4；不要二次编码。
6. 导出成功后不要点击“发布”“分享到抖音”或其他外部平台按钮。

## 验收

普通验收运行：

```bash
scripts/verify_video.sh "/绝对路径/成片.mp4"
```

包含 B-roll 或转场时，传入检查目录和逗号分隔的关键时间点：

```bash
scripts/verify_video.sh "/绝对路径/成片.mp4" "/绝对路径/inspection" "1,4.7,4.9,5.2,8.1,8.3,8.5"
```

验收必须同时满足：

- 剪映界面明确显示导出成功；
- 输出文件真实存在且大小大于 0；
- `ffprobe` 能读取视频流和音频流；
- 时长与原片接近，分辨率和帧率符合预期；
- 开头、正文、结尾与每个 B-roll 中点均正确；
- 每个转场至少能看到“原画面、混合帧、素材全显”，不能只有硬切；
- 原人声音频从头到尾存在，并在画面切换处连续；
- 二次逐词转写不再包含计划删除的口癖，相邻实词和语义保持完整；烧录字幕源片还要逐点抽帧，确认被删口癖不再出现于画面，跨剪点的旧字幕残留必须遮盖并重建；
- 原片、剪映草稿和最终成片的路径分别报告给用户。

在项目编辑目录保存 `project.md`：记录源文件、素材时间点、转场时长、草稿路径、终版路径、失败候选和验收结果。

## 当前版本的会员判断方法

会员状态会随剪映版本变化，每次都以界面实际标识为准。已验证过的一条成功路径是：本地导入 → 默认文本 → 免费描边样式 → 本地导出。曾观察到“智能剪口播”的一键删除标有 `SVIP`，“智能字幕”显示每月试用但在导出时要求登录；这些只能作为历史线索，不能当作永久价格或权限结论。

## 最终汇报

简洁说明：

- 成片做了哪些实际变化；
- 哪些功能因会员或登录限制没有使用；
- 视频规格、时长和文件大小；
- 原片、草稿、成片和预览图路径；
- 是否登录、购买、发布或覆盖过文件。
