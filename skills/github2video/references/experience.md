# 经验与案例

区分可复用方法、特定案例事实与未验证事项，旧结论不搬成新视频 PASS。

## 从已有工程提炼的方法

1. 先恢复批准状态，再收敛整片。时间线同时安排主体、动作、阅读和原速声音；不先制局部再补结构。计划有限，只解决当前任务。
2. 主体必须是真实内容。保留可用录屏、案例动态和结果，外层包装与角色配合它们。整套他人画面加旁栏、空卡片等待文字、静图撑全片都不能代替编排。
3. 动作要对应前后状态及操作落点，接触同帧反馈；角色、道具与独立效果分层。复刻按该段原效果的分组实现，不因别处有淡入就替换当前段落。
4. 正文推进和阅读同时规划，不能长模糊入场挤掉阅读，也不能靠字幕、边框或装饰运动充数。
5. 输入、引擎和输出分别留证。本机 AiToEarn 既有工程实际用 Author、Run、Build、Result 导出，再核观看副本原速音轨。入口和方法可复用，项目时码、声音哈希及文案不可照搬。
6. 图审、来源、OCR、解码、引擎执行、动态审片、听检与用户接受是不同结论。已认可版本绑定文件和哈希冻结；取现有文件先给，状态另列。
7. 任务中断先查原进程、日志和 Build；turn_aborted、99% 和预计 0 秒不是终态。工具出错不等于后台进程已退出。
