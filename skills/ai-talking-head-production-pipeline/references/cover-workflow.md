# 口播视频封面工作流

## 目标

封面要在手机缩略图中快速传达“这是谁、冲突是什么、为什么要点开”。它是独立的平台资产，不是从成片随机截一帧。

## 输入

- 定稿文案、已转写口播或经验收成片；
- 用户明确授权使用的真人视频或图片；
- 平台、比例和参考风格；
- 如有参考视频，先记录可见的字号层级、人物占比、强调色、安全区和信息密度。

## 步骤

### 1. 先定一个冲突

主标题优先使用“对象 + 纠偏”、“错误做法 + 正确方向”或“结果 + 核心变量”。默认 6–12 个中文字，最多两行主标题。不用主题词堆叠，不添加正文未证明的数字。

### 2. 选人物帧

1. 优先从无字幕、无大面积特效的原片抽取 4–6 帧。
2. 用联系表对比，检查睁眼、口型、头顶、手势、清晰度和背景可分离性。
3. 头顶必须完整；上方预留约 8%–12% 空间，避免生成时再次裁掉发顶。
4. 如用户未授权使用人脸，改用无人物封面，不从第三方来源抽取肖像。

### 3. 组织版式

- 一个主人物，一个主标题，一个强调色。
- 人物与标题分据两个区域，不在眼睛和嘴部叠字。
- 如果头脸大小已经合适、但半身在底部占比过大，不要继续整体缩小人物；保留头肩、麦克风和握麦的手，在手腕或下胸线附近自然渐隐下方前臂与躯干，避免生硬横切。
- 背景图形只解释主题，对比、流程和分类用简化卡片或连接线，不用无关 AI 符号填空。
- 小红书 9:16 默认左右留 120 px，顶部留 170 px，底部留 240 px，重要内容不进入交互覆盖区。

### 4. 生成与文字回退

1. 提示词明确原帧中必须保留的身份特征，并要求“不美化成另一个人”。
2. 使用 `EXACTLY` 列出允许出现的中文，并写明“无其他可读文字”。
3. 首次生成后逐字检查。有错字时做一次定向修复。
4. 仍有错字时，生成无字背景，使用本地已安装中文字体叠加文字。不反复重生整张图。

### 5. 验收

- 文字：逐字正确，没有多字、伪字、水印或平台 UI。
- 人物：身份一致，眼睛和手指自然，头顶完整，没有与原片矛盾的衣着。
- 可读性：按手机缩略图缩小后仍能在 1 秒内读出主标题。
- 构图：人脸不被文字遮挡，主体不被平台交互区遮挡。
- 尺寸：小红书默认 1080×1920 PNG。

## 项目记录

项目级 SOP 至少记录：参考链接或本地帧、学到的视觉特征、人物帧时码、标题、完整提示词、最终路径、尺寸和验收结果。参考链接只用于视觉学习，不代表允许复制其素材、品牌或论断。
