# 简单口播 → 动态成片模式

## 适用目标

用户只负责录制一条干净、稳定、构图简单的 9:16 真人口播。后续由 AI 辅助完成内容剪、语义配画、人物与画布布局、动效、字幕、封面和验收，并根据工程需要选择 Premiere Pro 或剪映专业版。

这里的“动态”不是每秒都有动画，而是让画面在讲解需要时切换状态，同时保留真人出镜带来的信任感。

## 从参考视频提炼出的画面语法

### 参考一：AI 自动生成整条口播画面

参考：`https://www.xiaohongshu.com/explore/6a8fe1b8000000002003450c`

可复用方法：

1. AI 先读取完整文稿，再按语义切成若干段。
2. 每段确定“应该出现什么画面”，必要时生成首帧、尾帧和视频提示词。
3. 把首尾帧交给视频模型生成短动画，再与原人声和字幕组合。
4. 成片不是单一 B-roll 叠加，而是在五种状态间切换：
   - AI 动画全屏，真人圆形小窗叠加；
   - 插画或动画卡片全屏，真人暂时退出；
   - 真人全屏，叠加大号步骤标题；
   - 信息画布同时展示首帧、尾帧和生成结果；
   - 真人全屏，旁边出现带边框的示例图。

### 参考二：信息画布与真人口播的节奏分配

参考：`https://www.xiaohongshu.com/explore/6aaf8845000000002603b72a`

可复用方法：

1. 开头用深色信息画布、标题、案例卡片和圆形真人小窗建立信息密度。
2. 主体大量回到简单真人全屏，只保留轻量身份条和细字幕。
3. 关键解释节点再调用信息画布，而不是持续堆动效。
4. 结论：复杂画面负责解释，真人全屏负责信任、停顿和观点表达。

### 本地已验证的布局状态

- `speaker_full`：真人全屏。
- `speaker_circle_canvas`：真人圆形小窗 + 信息主画布。
- `speaker_side_panel`：真人侧边竖幅 + 另一侧素材或流程。
- `canvas_only`：全屏插画、录屏或动画，原人声连续。
- `speaker_full_return`：关键视觉结束后回到真人全屏。

不得把第三方参考视频的素材、文案或包装直接复制进成片；只复用结构、节奏和布局方法。

## 录制输入标准

- 竖屏 9:16，建议 1080×1920、30 fps。
- 固定机位，胸口以上，眼睛接近画面上三分之一。
- 头顶和左右各留出可缩放、裁切的安全空间。
- 光线、白平衡和收音保持稳定；尽量不要使用已经烧录字幕的相机模板。
- 每句尽量只表达一个意思，句间保留约 0.3–0.6 秒自然停顿。
- 开头和结尾各多录约 1 秒，便于转场和结尾停留。
- 口误后整句重说，不要边说边解释口误。

若原片已有烧录字幕，不要假装可以直接关闭。应局部遮罩、重构画面或保留不可消除区域，并在交付说明中记录边界。

## 项目最小产物

保留原片不覆盖，并为本次任务建立独立目录：

```text
source/                         原始口播，只读保留
project.md                      目标、风格、时长、编辑器与约束
source_probe.json               编码、帧率、分辨率、时长
transcript_words.json           带词级时间戳的转写
content_plan.json               保留段、删除段、理由
content_cut.mp4                 完成内容剪的连续人声主片
asset_inventory.md              素材来源与用途
visual_plan.json                语义配画和布局状态
generated_visuals/              自制卡片、透明动画、首尾帧与短动画
editor/                         Premiere 工程或剪映草稿
final/                          独立命名的 MP4 成片与封面
inspection/                     接缝帧、抽帧、联络表和验收记录
```

## 标准执行流程

### 1. 建立媒体基线

先用 `ffprobe` 记录原片时长、帧率、分辨率、音轨和旋转信息，再做带词级时间戳的本地转写。不得直接在原片上破坏性操作。

### 2. 先做内容剪，再做视觉剪

只删除语义空白、明显口误、重复重说和异常长停顿。同步裁切音视频，保留必要呼吸和自然停顿。内容剪完成后重新转写一次，用新时间轴作为所有视觉标注的唯一坐标。

### 3. 逐句建立语义配画表

| 口播功能 | 默认画面 | 可选增强 |
|---|---|---|
| 钩子、核心观点 | `speaker_full` | 关键词弹入、轻推近 |
| 具体案例、场景 | 带边框 B-roll 或 `speaker_circle_canvas` | 真实录屏、现场素材 |
| 2–4 个并列项 | 卡片画布 + 真人小窗 | 卡片依次入场 |
| 流程、因果、对比 | 透明流程动画 + 真人小窗 | 连线、节点高亮 |
| 软件操作 | 真实录屏 + 侧边真人 | 光标强调、局部放大 |
| 难以实拍的抽象概念 | AI 首尾帧短动画 | 只在确有解释价值时使用 |
| 观点、过渡、结尾 | `speaker_full_return` | 身份条或一句总结 |

一个视觉必须对应一句明确口播。找不到对应句子时，不要为了“热闹”强加素材。

### 4. 按优先级制作素材

素材优先级：真实录屏或真实资料 > 自制信息图和透明动画 > AI 生成视觉 > 泛化库存素材。

需要 AI 视频时：

1. 为该语义段写一句画面目标。
2. 生成一致风格的首帧和尾帧。
3. 写明主体动作、镜头运动、时长、画幅和禁止项。
4. 生成 2–4 秒短动画，而非长篇替代真人。
5. 检查乱码、错误 UI、品牌误用、身份混淆和不受控闪烁。

### 5. 用布局状态机组织节奏

默认状态流：

```text
钩子真人全屏
  → 必要时高密度信息画布 + 真人小窗
  → 真人全屏
  → 关键案例或流程画布
  → 真人全屏回归
  → 结尾总结与行动指令
```

- 不要每句话都切画面。
- 信息画布连续约 8–12 秒后，优先回到真人建立呼吸感。
- 人物缩放和位移使用缓入缓出；常见过渡约 0.25–0.45 秒。
- 圆形小窗和侧边人物必须保持脸部锚点稳定，不能在状态切换时跳脸。
- 一个视频只用一套主色、卡片圆角、描边和阴影规则。
- 大标题、字幕和画布卡片不能同时争夺同一视觉层级。

`visual_plan.json` 至少记录：

```json
{
  "items": [
    {
      "source_after_cut": [3.2, 7.8],
      "spoken_function": "解释三个输入材料",
      "layout": "speaker_circle_canvas",
      "visual_kind": "motion_graphic",
      "visual": "三张材料卡片依次入场",
      "transition": "ease_in_out_0.35s",
      "on_screen_text": ["销售记录", "报销表", "制度文件"]
    }
  ]
}
```

### 6A. Premiere Pro 路线

适合多层合成、精确关键帧、复杂遮罩和需要重复复用模板的项目。

1. 将完成内容剪的口播作为连续主序列或嵌套序列。
2. 分离轨道：真人主片、B-roll/录屏、透明动画、字幕、音效。
3. 用位置、缩放、裁切或蒙版实现五种布局状态。
4. 对关键帧使用缓入缓出；切换前后逐帧检查脸部位置和边界。
5. 字幕最后进入，避免布局调整后重复返工。
6. 自动化可以批量创建序列、插入素材和写入参数，但必须回读时间线并抽帧验收。

### 6B. 剪映专业版路线

适合快速生产、字幕和基础动效占比更高的项目。

1. 新建独立草稿，导入口播主片、配画、透明动画和字幕。
2. 若多轨、关键帧和字幕导入在当前版本中稳定，直接按相同轨道结构搭建。
3. 若原生多轨不稳定，先在外部生成保持原人声连续的确定性预合成，再新建空白草稿，只导入一个主视频完成最终导出。
4. 不得把“草稿可预览”当成“成片已交付”；必须导出独立 MP4 后再验收。

### 7. 字幕和声音

- 默认使用细白字、轻描边或轻阴影，不使用贯穿全片的大黑底字幕条。
- 每行保持可一眼读完，断句服从语义，不机械按字数切分。
- 原人声必须连续，画面替换不得导致声音跳变。
- 背景音乐只做气氛层，不能掩盖辅音；音效仅服务于卡片、节点或状态切换。

### 8. 独立生成封面

1. 从成片中选 4–6 张表情、构图和光线合格的候选帧。
2. 从口播提炼 6–12 个字的结果型标题，不能添加正文没有的结论或数据。
3. 使用一张真人候选帧或一个与主题直接相关的主视觉，避免多个小图平均分配注意力。
4. 延续成片主色和字体，保证手机缩略图下仍能读清。
5. 导出 1080×1920 PNG，并检查中文、边距和平台裁切安全区。

### 9. 成片验收

- 原片、内容剪、工程、成片和封面均独立命名，不覆盖旧版本。
- 逐点检查所有删除接缝，没有半个音节、黑帧或突兀呼吸。
- 检查布局切换前、中、后帧，确认人物没有跳位、卡边或被字幕遮挡。
- 检查卡片数量、顺序、文字与口播完全一致。
- 检查 AI 画面没有乱码、错误品牌、伪造界面或与正文无关的装饰。
- 检查字幕错字、断句、出入点以及是否残留制作备注。
- 结尾保留约 0.5–1 秒稳定画面，不在最后一个字上突然截断。
- 用 `ffprobe` 核对成片可读、音视频轨存在、时长合理；再做多时间点抽帧联络表。

只有独立 MP4 已导出并通过以上验收时，状态才能写为 `final-verified`。

## 参考核对的本机成功路径

- 参考视频通过系统 Chrome、默认用户目录中的 `jackie` profile 只读核对。
- 小红书纯净链接曾返回 404；沿用用户提供的完整链接（含当时有效的 `xsec_token`）可正常打开。后续复核应优先使用用户当次提供的完整链接，不自行开启空白 profile 或调试端口。
- 核对过程中不点赞、不关注、不评论、不发布。
