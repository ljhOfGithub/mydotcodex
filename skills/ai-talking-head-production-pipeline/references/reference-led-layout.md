# 参考驱动的演示主画布

当参考视频的主要语言不是普通 B-roll，而是“真人讲解 + 演示文稿式信息画布”时使用本附录。

## 先拆视觉语法

至少抽查开头、两个正文节点、信息密集段、一次真人回场和结尾，记录：

- 真人状态：全屏、圆形小窗、侧栏、退场；
- 主画布模板：证据卡、并列卡、步骤流、数据重点、真实场景；
- 标题层级：章节眉题、主标题、来源条、字幕、身份浮标；
- 切换频率：连续信息画布多长时间后回到真人；
- 强调语言：颜色、描边、字号变化和进出动画。

不要照抄参考视频的文字、数据或品牌装饰，只复用构图和信息层级。

## 默认状态机

1. `speaker_full`：开头和结论，全屏真人建立信任。
2. `speaker_circle_canvas`：关系、证据、步骤和数据段，主画布占主要空间，真人保持在不遮挡字幕的小窗。
3. `speaker_side_scene`：需要同时看到真人与真实工作场景时使用。
4. `canvas_only`：极短的信息密集段可让真人退场，但通常不超过 4 秒。
5. `speaker_full_return`：信息画布连续 8–12 秒后至少安排一次真人回场。

状态切换默认使用 0.3–0.5 秒 ease-in-out。人物缩放必须围绕经过抽样确认的人脸中心；圆形、侧栏和回到全屏共用同一裁切锚点。

## 信息主画布

- 使用一种稳定的背景、圆角、边框、阴影和强调色，避免每个镜头像不同模板。
- 每个画面只表达一个冲突、证据、分类或流程；正文卡片通常不超过四块。
- 只有具体、可核实且确实帮助观众理解的外部出处才显示来源条；没有外部来源时直接省略，不用“口播观点”“本段摘要”之类内部元数据填位，也不伪造论文、数据和机构背书。
- “逐步高亮”“口播中的四类材料”“素材化呈现”等制作说明或调试标签不得烧入观众画面；如果一条底栏不能帮助观众理解当前口播，就省略。
- 口播明确枚举若干对象或步骤时，画面中的对象数量、顺序和退出时间必须一致；最后一项说完并稳定可读后再退出，不得用三步图概括四句口播。
- 关键词高亮使用一种主色；不要同时用多种跳色争夺注意力。
- 字幕最后绘制，保持在平台安全区，不与来源条、人物小窗和身份浮标重叠。

## 身份浮标

- 只使用用户提供或已核实的姓名、学校、专业、职务等事实。
- 默认在全屏真人阶段出现，位于面部之外、字幕之上；进入圆形小窗或侧栏后隐藏，避免重复标签。
- 推荐两级文字：机构/身份为主行，专业/角色为副行；两行必须位于同一轻量底板内，不得拆成颜色割裂的两块。底板可按参考风格使用浅色或半透明磨砂，但必须保证文字对比度，并避开人脸、手部和字幕安全区；不做夸张认证徽章。
- 验收开头、人物缩位前、缩位后和结尾回场，确认不遮脸、不遮字幕、不越过画面安全区。

## 验收

- 抽查每次状态切换的前帧、混合帧、稳定帧和退出帧。
- 检查人物头部和下巴在所有小窗状态完整可见。
- 全屏真人上的背景渐变或遮罩必须柔和延伸到画面边缘，不得在字幕顶部、身份浮标底部或人脸附近硬终止；抽帧检查是否出现贯穿画面的水平色带。
- 连续信息画布不得让真人消失过久；普通连接句回到真人。
- 卡片文字在手机尺寸仍可读，且没有参考视频原文或未经核实的数据。
- 修改或删除任何制作标签后，先盘点公共渲染器和预制动画中的全部可见字符串，再对每种不同版式至少抽取一帧实看；不得因为已删用户指出的一条，就声称全片通过。
- 检查最后一个真实音节之后的视觉余量：除非用户明确要求硬切，保留约 0.5–1 秒自然停留或柔和淡出，避免嘴部仍在动作时文件直接结束。
