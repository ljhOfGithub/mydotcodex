# Hypit 旁白制作（声音免审核）

执行[声音免审核门](../_references/声音免审核门.md)。用户指定Hypit时仍由Hypit实际编排；音乐MV沿用指定原唱。

1. 恢复现有声音文件、文案和参数，沿用指定声线。默认本地VoxCPM2及已核实jackie-reference.wav，不克隆参考作者，不因审核阈值重配声音。
2. 按完整语义段生成，默认自然、有活力；续接text只含实际口播。无需先做开头三句候选、普通/激动A/B或用户试听选择。
3. 按实际音轨时长规划镜头和字幕，ASR可用于字幕定位，不作声音质量或内容审核。保留原速和实际生成参数，不靠大幅后期拉伸挤时间线。
4. 生成后直接配入已授权工程，不等待声音认可。只核文件存在、解码及指定原速使用；画面图审和视觉检查按各自规则。
5. 保存来源、音轨哈希和当前输出；旧声音审核脚本只返回VOICE_REVIEW_NOT_REQUIRED，不声明听审或用户批准。

[制作说明](references/workflow.md)提供当前流程。用户当次明确要求试听或改声时处理该次请求，不恢复全局审核。
