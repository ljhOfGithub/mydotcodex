# 来源与本机验证

上游仓库：https://github.com/YANZHANLIN/clawd-avatar-skill

固定版本：`5d7d7c51f451c25fa351dd7ee4536f4d2fbb341a`。

安装名称为 `clawd`，由 Codex 官方技能安装脚本安装。上游文件保持原样；本文为本机补充记录。

验证日期：2026-11-09。`bash -n scripts/render.sh` 通过；标准角色 PNG 导出成功，尺寸为 560×560。执行脚本无网络请求；PNG 导出会调用本机 ffmpeg。静态导出自带深色背景，并非透明图。

本机使用时，以实际安装目录为准，不能照抄上游示例中的 `~/.claude/skills/clawd`。Clawd 标准形象没有嘴巴。跨场景影片由用户指定的 Hypit 编排；先交多张关键画面并等待用户明确通过，再制作视频。

动画模板存在静态和动画身体矩阵的规格差别，使用时须按相应模板保留比例。模板中的增量随机运动应在影片中转换为按帧确定的状态；气泡使用的颜色应显式指定，避免照抄未定义的配色项。
